# starbucks-customer-analysis

This project analyzes Starbucks customer ordering patterns (2024–2025) to uncover insights into customer behavior, sales performance, and operational trends.

## Project Overview
- Analyzed customer spending behavior, purchasing channels, and product preferences
- Developed an interactive dashboard using Power BI
- Conducted regression analysis using Python to evaluate the impact of rewards membership on customer spending

## Key Insights
- Rewards members spend **$1.63 more on average** (statistically significant)
- Peak order time is **7:00 AM**
- Highest spending age group is **18–24**
- Most purchased products are **Refreshers and Tea**
- Mobile app users show higher spending behavior

## Tools Used
- Python (Pandas, Statsmodels)
- Power BI
- Microsoft Excel
